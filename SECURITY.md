# Security Policy / 安全政策

[English](#english) | [简体中文](#简体中文)

## English

Security fixes target the latest published release and `main`. Older releases may be unsupported unless a fix can be backported safely.

Do not open a public issue for a vulnerability. Use [GitHub private vulnerability reporting](https://github.com/TonyWang-hub/deepseek-harness-desktop/security/advisories/new). Include the affected version and architecture, impact, reproduction steps, and logs with credentials and personal paths removed. You should receive an acknowledgement within five business days. Coordinated disclosure timing depends on severity and release readiness.

This policy covers the desktop shell, process supervision, local transport, packaging, updater, and release pipeline. A problem reproducible in the pinned official `dsh web` profile without this shell belongs upstream. This project currently offers no bug bounty, but good-faith research that avoids privacy violations, data destruction, and service disruption is welcome.

## 简体中文

安全修复面向最新已发布版本和 `main`。除非可以安全回移，旧版本可能不再受支持。

请勿为漏洞创建公开 Issue。请使用 [GitHub 私密漏洞报告](https://github.com/TonyWang-hub/deepseek-harness-desktop/security/advisories/new)，并提供受影响版本与架构、影响、复现步骤和已删除凭据与个人路径的日志。维护者将尽量在五个工作日内确认，协调披露时间取决于严重程度和发布准备情况。

本政策覆盖桌面壳、进程监管、本地传输、打包、更新器和发布流水线。如果问题在不使用本桌面壳的锁定官方 `dsh web` profile 中也能复现，应向上游报告。本项目目前不提供漏洞奖金，但欢迎不侵犯隐私、不破坏数据、不干扰服务的善意安全研究。
