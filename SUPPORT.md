# Support / 支持

[English](#english) | [简体中文](#简体中文)

## English

- Questions, setup help, and usage ideas: [GitHub Discussions](https://github.com/TonyWang-hub/deepseek-harness-desktop/discussions).
- Reproducible desktop bugs: use the bug report issue form.
- Desktop feature requests: use the feature request issue form.
- Vulnerabilities: use [private vulnerability reporting](https://github.com/TonyWang-hub/deepseek-harness-desktop/security/advisories/new).
- Behavior reproducible in the official Web profile: report it to the DeepSeek Harness upstream project.

Include the desktop version, macOS version, CPU architecture, and reproduction steps. On v0.4.0 or later, use the tray or Dock menu's **Export Diagnostics…** action and review the JSON before attaching it; do not append raw Host output, environment dumps, or session content. Never post API keys, signing material, credentials, or private workspace content.

When upgrading from v0.4.2 or earlier, install the matching v0.4.4 DMG manually. The real signed v0.4.1→public v0.4.2 proof exposed the update after proxy transfer but before native Squirrel readiness; v0.4.3 fixed that gate, and payload-neutral v0.4.4 is its public proof target. The v0.4.3→v0.4.4 proof is in progress and automatic installation remains unclaimed until it succeeds; include exported diagnostics and updater errors when reporting a related issue.

## 简体中文

- 使用问题、安装帮助和使用想法：[GitHub Discussions](https://github.com/TonyWang-hub/deepseek-harness-desktop/discussions)。
- 可复现的桌面端缺陷：使用缺陷报告 Issue 表单。
- 桌面端功能建议：使用功能建议 Issue 表单。
- 安全漏洞：使用 [私密漏洞报告](https://github.com/TonyWang-hub/deepseek-harness-desktop/security/advisories/new)。
- 在官方 Web profile 中也能复现的问题：向 DeepSeek Harness 上游项目报告。

请提供桌面端版本、macOS 版本、CPU 架构和复现步骤。v0.4.0 或更高版本请通过托盘或 Dock 菜单的 **Export Diagnostics… / 导出诊断…** 生成报告，检查 JSON 后再附加；不要自行加入原始 Host 输出、环境变量 dump 或会话正文。不得公开 API Key、签名材料、凭据或私有工作区内容。

从 v0.4.2 或更早版本升级时，请手动安装匹配架构的 v0.4.4 DMG。正式签名 v0.4.1→公开 v0.4.2 的真实证明在 proxy 传输完成、原生 Squirrel ready 前就暴露了更新；v0.4.3 已修复该 gate，载荷不变的 v0.4.4 是公开证明目标。v0.4.3→v0.4.4 证明正在进行，成功前仍不声称自动安装可用；报告相关问题时请附上导出的诊断与 updater 错误。
